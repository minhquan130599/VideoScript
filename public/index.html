Cấu Hình OpenCode Go API

Hệ thống kết nối trực tiếp cổng OpenCode Go (https://opencode.ai/zen/go/v1). Theo quy chuẩn OpenCode Go: GPT dùng giao thức /responses và Claude dùng giao thức /messages.

Key được lưu an toàn cục bộ trong trình duyệt của bạn (localStorage).
Tự động chuyển hướng chính xác đến /responses hoặc /messages theo tài liệu OpenCode Go.
16,000 Tokens
Cho phép tự động điều chỉnh token theo nhu cầu để tránh bị cắt cụt JSON khi tạo nhiều video.
